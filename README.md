# Mijn Stemming

Officiële installatiebestanden van Mijn Stemming voor Windows 10 en 11 (64-bit).

[Uitleg en installatie](https://mijn-stemming.nl/download.html) · [Privacy](https://mijn-stemming.nl/privacy.html)

Het installatiebestand bevat alleen het programma. Accounts en dagboeken worden op je eigen apparaat aangemaakt en maken geen deel uit van deze downloads. Broncode en privésymbolen worden hier niet gepubliceerd.

Download het MSI-bestand bij Releases. De bijbehorende SHA256-controlesom staat in SHA256.txt. De app heeft nog geen digitaal uitgeverscertificaat.
